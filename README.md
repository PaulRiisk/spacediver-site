# Space Diver

The website for **Space Diver**, a top-down roguelite built around one rule:
stand to shoot, move to dodge.

A small static site: a short page about the game, plus the legal pages required
for publishing in Germany. Hosted on GitHub Pages, no cookies, no tracking,
no build step.

- [Play the free demo](https://devraaven.itch.io/spacediver)
- [Watch the trailer](https://www.youtube.com/watch?v=DGfWt6BgfVw)

**Live:** <https://paulriisk.github.io/spacediver-site/>

The game itself is made in Godot and lives in a separate, private repository.
